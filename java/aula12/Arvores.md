# Arvores

- Estrutura de Dados excelente para guardar e buscar
- tipos:
  - Genérica: um pai e n filhos
  - Binaria: um pai e no maximo 2 filhos
    - arvore binaria de pesquisa: arvore ordenada
    - todos os elementos menores que a raiz ficam à esquerda e todos os elementos maiores que a raiz ficam à direita

"Guardar bem pra buscar bem"

- Conceitos
- nó ou nodo de cedula
- raiz de arvore ou subarvore
- nos folhas

PERCURSO

- RED = pre-fixado
- ERD = in-fixado
- EDR = pos-fixado
